# BestMonth

## Publish
Upload all files to a GitHub repository and enable GitHub Pages.

## Edit ideas
Open `script.js`.

Replace:

const ideas = ...

Example:

{
  title: "Sunset picnic",
  text: "Pack snacks and drive somewhere with a nice view.",
  link: "https://maps.google.com/...",
  nsfw: false
}

Fields:
- title
- text
- link (optional)
- nsfw (true/false)

Opened cards are remembered in the browser.
